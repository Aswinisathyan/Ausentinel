How accurate is Ausentinel?

The model was tested twice: on the development set, which uses the same six attack methods it was trained on, and once on the evaluation set, which uses 13 attack methods it had never seen. The second test is the honest one.

What this means. On attack methods it was trained on, Ausentinel misses about {{ pct(dev.apcer) if dev else "a small share" }} of spoofs. On new attack methods it misses {{ pct(ev.apcer) if ev else "far more" }}. Real voices are rarely flagged in either test. A result of "bona fide" is therefore much weaker evidence than a result of "spoof".
